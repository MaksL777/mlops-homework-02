# Домашнє завдання №2: Створення VPC та EKS-кластера через Terraform

## Мета проєкту

Автоматизація створення базової інфраструктури для ML-сервісів в AWS.
Проєкт розділений на два незалежних модулі (`vpc` та `eks`), які зв'язані між собою через `terraform_remote_state`.

## Структура

- `/vpc` — конфігурація мережі (VPC, Subnets, NAT Gateway). Використовується модуль `terraform-aws-modules/vpc/aws`.
- `/eks` — конфігурація Kubernetes кластера та Node Groups. Використовується модуль `terraform-aws-modules/eks/aws`.

> **Примітка щодо GPU-nodes:** Щоб уникнути високих витрат в AWS, група `gpu-nodes` використовує інстанси `t3.micro` (замість реальних GPU-інстансів), імітуючи ізоляцію workload-навантажень згідно з вимогами завдання.

---

## Інструкція з розгортання (Порядок Apply)

**ВАЖЛИВО:** Порядок запуску є критичним. EKS-кластер залежить від мережі (VPC), тому **спочатку необхідно розгорнути конфігурацію vpc/, а вже потім eks/**.

### Крок 1. Створення мережі (VPC)

Перейдіть у директорію vpc/, ініціалізуйте Terraform і розгорніть мережу:

    cd vpc
    terraform init
    terraform apply

### Крок 2. Створення кластера (EKS)

Після успішного створення VPC перейдіть до директорії eks/. Цей модуль прочитає дані створеної VPC через terraform_remote_state та створить кластер із двома Node Group (cpu-nodes та gpu-nodes):

    cd ../eks
    terraform init
    terraform apply

---

## Перевірка працездатності (Підключення до кластера)

Коли розгортання EKS завершиться, необхідно підключитися до кластера і перевірити статус worker nodes:

    aws eks --region us-east-1 update-kubeconfig --name mlops-eks-cluster
    kubectl get nodes

Очікуваний результат: У виводі мають відобразитися дві ноди (cpu та gpu) у статусі Ready.

---

## Видалення ресурсів (Порядок Destroy)

Щоб уникнути зайвих витрат, ресурси необхідно видаляти у зворотному порядку. EKS залежить від VPC, тому спочатку видаляємо кластер, а потім мережеву інфраструктуру:

### 1. Видалення кластера (EKS):

    cd eks
    terraform destroy

### 2. Видалення мережі (VPC):

Тільки після повного видалення EKS:

    cd ../vpc
    terraform destroy
